# Halal Scanner V2 — EFTNIX

Responsive barcode product lookup with expanded ingredient intelligence and E-number explanations.

## V2 additions
- Product lookup with Open Food Facts API v2 and fallback v0 endpoint.
- More informative connection, timeout and not-found errors.
- Expanded E-number notes for selected additives.
- Ingredient intelligence rules for selected animal-derived, source-dependent and common plant-derived ingredients.
- Camera scanning in supported browsers on HTTPS.
- Responsive interface and language toggle control.

## Deploy
Upload all files in this folder to the root of your GitHub repository, replacing the previous version. Keep the repository Pages settings on `main` and `/(root)`.

## Important limitations
This is a rule-based information aid, not a certified AI halal decision system, halal certificate verifier or religious authority. It does not independently verify ingredient supply chains, manufacturing aids, cross-contamination, certificate authenticity or expiry. Ingredient rules must be reviewed by qualified halal experts and scholars before public release.
Product data is sourced from Open Food Facts and may be incomplete, inaccurate, outdated or user-contributed. Missing information is not proof of halal or haram. Follow Open Food Facts API terms, attribution and ODbL licensing requirements.
